# Brand asset source

The Hisense wordmark used in the integration icon and logo images is based on the current Hisense logo from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Hisense.svg), sourced there from [global.hisense.com](https://global.hisense.com/). The Commons file is identified as a public-domain text logo and notes that the Hisense mark remains a trademark. It is used here only to identify compatibility with Hisense TVs.

The icon and logo PNG variants were generated from that wordmark for Home Assistant's custom integration `brand/` image format. No Home Assistant logo is included; Home Assistant's branding guidance says custom integrations should not ship Home Assistant-branded images.
